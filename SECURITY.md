# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Trovec, please report it responsibly. **Do not open a public issue.**

Instead, please email the maintainer directly or use [GitHub's private vulnerability reporting](https://github.com/frandi/trovec/security/advisories/new).

Include as much detail as possible:

- Description of the vulnerability.
- Steps to reproduce.
- Potential impact.

We will acknowledge your report promptly and work with you to address the issue before any public disclosure.
